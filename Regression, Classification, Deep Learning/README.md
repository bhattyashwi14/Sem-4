# Regression, Classification and Deep Learning

This folder contains the classwork and practical implementations performed during the **T2 phase of Semester 4**, based on the syllabus of *Fundamentals of Computer Science using Python – II*.

---

## Overview

This module focuses on building a strong foundation in **Machine Learning concepts**, including:

* Regression models
* Classification algorithms
* Introduction to Deep Learning

The aim is to understand how models are trained, evaluated, and applied to real-world datasets.

---

## Topics Covered

### Regression – Model Training and Evaluation

* Simple Linear Regression
* Multiple Linear Regression
* Polynomial Regression
* Model evaluation using:

  * R² (R-squared)
  * MAE (Mean Absolute Error)
  * MSE (Mean Squared Error)

---

### Classification – Model Training and Evaluation

* k-Nearest Neighbours (kNN)
* Decision Tree (Entropy-based)
* Random Forest
* Support Vector Machine (SVM)

Model evaluation using:

* Confusion Matrix
* Accuracy
* Error Rate
* Sensitivity & Specificity

---

### Introduction to Deep Learning

* Basics of Neural Networks
* Activation Functions:

  * ReLU
  * Sigmoid
  * Softmax
* CNN fundamentals:

  * Convolution
  * Pooling
  * Dropout
* Introduction to Transfer Learning

---

## Purpose

* To develop a clear understanding of **supervised learning (regression vs classification)**
* To learn how to **train and evaluate machine learning models**
* To gain introductory knowledge of **deep learning concepts and architectures**

---

All files in this folder represent **hands-on implementation and in-class learning**, aligned with the academic curriculum.
